🇹🇭 Longdo Map API (ของไทย • แม่นตรอกซอยที่สุด) ⭐ แผนที่หลักแนะนำ (Default Primary) พร้อมใช้ (Official Key)
ฐานข้อมูลแผนที่สัญชาติไทย ละเอียดลึกถึงตรอก ซอย ซอกตึก เลขที่บ้าน และจุดรับส่งทั่วประเทศ
⚡ Smart Geocoder (ฟรี • ไวสุด • สำรอง) พร้อมใช้ทันที
ผสานฐานข้อมูลแลนด์มาร์กกรุงเทพฯ ในตัว (0ms) + Photon Autocomplete (OSM) ตอบสนองเร็ว ไม่ติด Rate Limit 1 req/sec และมี Local Cache
🌐 Google Places API (ครอบคลุมทั่วโลก)
ค้นหาสถานที่ ธุรกิจ ห้างร้าน และ POI ครอบคลุมทั่วไทยและทั่วโลก
🌍 Nominatim OpenStreetMap (ฟรีแบบดั้งเดิม)
เซิร์ฟเวอร์ฟรีของ OpenStreetMap (มี Debounce 600ms + AbortController ป้องกัน 429)
คำแนะนำสถาปัตยกรรมระยะยาว (Backend Caching Proxy)
สำหรับการให้บริการจริงที่มีผู้ใช้จำนวนมาก แนะนำให้ตั้ง Node.js / Express หรือ Cloudflare Workers Proxy ทำหน้าที่แคชผลลัพธ์พิกัดใน Redis / Memory และช่วยซ่อน API Key ไม่ให้รั่วไหลทาง Frontend
ดูตัวอย่างโค้ด Proxy (Node.js Express / Cloudflare)
// ตัวอย่าง Node.js Express Geocoding Cache Proxy const express = require('express'); const axios = require('axios'); const app = express(); const cache = new Map(); // หรือใช้ Redis app.get('/api/geocode', async (req, res) => { const q = (req.query.q || '').trim().toLowerCase(); if (cache.has(q)) return res.json(cache.get(q)); // เรียก Longdo Map / Google Places อย่างปลอดภัย const response = await axios.get(`https://search.longdo.com/mapsearch/json/search`, { params: { keyword: q, key: process.env.LONGDO_KEY } }); cache.set(q, response.data); res.json(response.data); }); app.listen(3000);
